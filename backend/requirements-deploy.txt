# Trimmed dependency set for deploying the live backend (Render). Excludes
# packages only used by the offline satellite-reprocessing script
# (scripts/tn_satellite_indices_pipeline.py) and dev/test tooling — none of
# app/ imports rasterio, pystac-client, planetary-computer, rasterstats, or
# shapely (verified via grep), and pulling in rasterio's GDAL-linked wheel
# on a platform it may not have a prebuilt wheel for is unnecessary risk on
# a deploy that doesn't use it. Regenerating tamil_nadu_dataset/*.csv still
# needs the full backend/requirements.txt, run locally.

# sentence-transformers pulls in torch, and PyPI's default torch wheel bundles
# the FULL CUDA toolkit (nvidia-cublas, nvidia-cudnn, nvidia-nccl, triton...) —
# multiple hundred MB to 1GB+ of GPU libraries that are pure dead weight on
# Render's CPU-only instances. This forces the CPU-only build instead, which
# meaningfully shrinks install size and (likely) the memory footprint and
# import time that were making the health check time out.
--extra-index-url https://download.pytorch.org/whl/cpu
