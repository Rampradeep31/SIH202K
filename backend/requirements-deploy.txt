# sentence-transformers (semantic embedding search) is deliberately EXCLUDED
# from this deploy tier. It pulls in torch, and even forced to the CPU-only
# wheel, torch + transformers + the loaded model pushed this app over
# Render's free-tier 512MB limit — confirmed via an actual "Out of memory
# (used over 512Mi)" deploy failure. app/rag/copilot.py already has a real,
# always-tested fallback for exactly this: its sentence-transformers import
# is wrapped in try/except, and TF-IDF (scikit-learn, already a dependency
# above) is *always* built as a parallel index regardless of which path
# succeeds. Without this package installed, that except branch fires, logs
# a warning, and the RAG copilot runs entirely on TF-IDF — a real quality
# trade-off (n-gram term matching instead of dense semantic embeddings),
# not a crash or a mocked response. Re-add sentence-transformers==6.0.1
# here (plus the CPU-torch --extra-index-url block, see git history) if
# you move to a paid Render plan with more memory.
